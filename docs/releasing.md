# Releasing

The Homebrew formula lives in [juanjsebgarcia/homebrew-tap](https://github.com/juanjsebgarcia/homebrew-tap) and builds from the tagged source tarball, so this repository must be public for `brew install` to work.

1. Bump `toolVersion` in `Sources/Core/DisplayAudio.swift`, plus `CFBundleShortVersionString` and `CFBundleVersion` in `Resources/Info.plist`. Run `make strings` and `make icon` if either changed, then `make clean all` and test the app by hand. Commit.
   Run `make test`; CI runs the same on every push.

   Then the hardware checklist, on a Mac with at least two external displays. None of this can be automated:
   - Connect the displays together, so at least one comes up with no sound, and confirm the menu shows it as No Sound within about 10 s.
   - Fix Now on that display: it goes black for about 3 s and comes back with sound; other displays are reported if they lose sound.
   - With Fix Monitor Speakers Automatically on, replug the speakers' display: a fix happens only after the settle and confirmation wait, and at most once.
   - Start a call (any app using the microphone) with the speakers' display silent: the fix waits and says so.
   - Quit during a fix: the app quits only after the display is back on.
   - `loudstation status` and `loudstation fix` behave the same as the menu.
   - Open the menu in two other languages (`open -a LoudStation --args -AppleLanguages '(de)'`): nothing clipped or overlapping.
   - Check for Updates… says it is up to date. Then turn off Check for Updates Automatically (so a real check does not clear the fake), fake a newer release and relaunch: Update Available appears and its alert matches the install type (Homebrew or source).
     ```sh
     defaults write io.github.juanjsebgarcia.loudstation latestVersion 9.9.9
     defaults write io.github.juanjsebgarcia.loudstation latestReleasePage https://github.com/juanjsebgarcia/loudstation/releases/tag/v9.9.9
     ```
2. Tag and push: `git tag -s vX.Y.Z -m vX.Y.Z && git push origin vX.Y.Z`. Do not publish the GitHub release yet (step 6).
3. Get the checksum of GitHub's tarball. It is generated by GitHub, so a local `git archive` gives a different checksum:
   ```sh
   curl -sL https://github.com/juanjsebgarcia/loudstation/archive/refs/tags/vX.Y.Z.tar.gz | shasum -a 256
   ```
4. In the tap, update `url` and `sha256` in `Formula/loudstation.rb`, then check it:
   ```sh
   brew audit --strict --online juanjsebgarcia/tap/loudstation
   brew install --build-from-source juanjsebgarcia/tap/loudstation
   brew test juanjsebgarcia/tap/loudstation
   ```
5. Commit and push the tap.
6. Publish the GitHub release last: `gh release create vX.Y.Z --verify-tag --title vX.Y.Z --notes ...`. The app's update check reads `releases/latest`, which ignores bare tags, drafts and pre-releases. Publishing only after the tap is pushed means Update Available never appears before `brew upgrade` can deliver the new version.
